# images/

Put your example media here — one file per keyword.

- Images: `.jpg`, `.png`, or `.webp`
- Motion: animated `.gif` (or `.webp`) so it plays in the card

**Naming:** match the `"media"` path in `data.json`, e.g. a keyword with
`"media": "images/volumetric-lighting.jpg"` needs a file named
`volumetric-lighting.jpg` in this folder.

Cards without a matching image show a "No image yet" placeholder — so the
site works fine even before you've added every picture.
